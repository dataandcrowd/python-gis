5  Shiny Functions and Reactivity

5.1 Story Problem: Filter Auckland Zones and Update the Map

Imagine building a dashboard for Auckland Council planners:

  • The Challenge: A user selects a subset of SA2 areas using a dropdown menu
  • The Expectation: The summary table updates immediately with statistics for selected areas
  • The Magic: The map refreshes showing only selected regions—without recomputing everything
  • The Reality: This “just works” through Shiny’s reactive programming model

This section teaches you how to build applications that feel responsive and intelligent, updating only what’s necessary when users interact with controls.

5.2 What You Will Learn

  • Define clean, maintainable UI and server functions
  • Use reactive calculations to avoid repeated computation
  • Structure applications so maps and tables update predictably
  • Implement efficient filtering and data transformation patterns
  • Build multi-output dashboards with shared reactive data

5.3 The Shiny Architecture

5.3.1 Three-Layer Model

Every Shiny application has three components:

from shiny import App, ui

# 1. UI: What users see
app_ui = ui.page_fluid(
    ui.h2("My Dashboard"),
    ui.input_slider("value", "Select", 0, 100, 50),
    ui.output_text("result")
)

# 2. Server: What happens behind the scenes
def server(input, output, session):
    @output
    @render.text
    def result():
        return f"You selected: {input.value()}"

# 3. App: Combining UI and server
app = App(app_ui, server)

5.3.2 Key Principles

1. Load Data Once

# Load outside server function - happens once at startup
regions = gpd.read_file('data/auckland_sa2.gpkg')

def server(input, output, session):
    # Data already loaded - use it here
    pass

2. Use Pure Functions for Transformations

def calculate_density(gdf, pop_column='population'):
    """Pure function: same inputs → same outputs"""
    gdf = gdf.copy()
    gdf['area_km2'] = gdf.geometry.area / 1_000_000
    gdf['density'] = gdf[pop_column] / gdf['area_km2']
    return gdf

# Use in server
def server(input, output, session):
    @reactive.Calc
    def processed_data():
        return calculate_density(regions)

3. Use Reactives for Filtered Views

@reactive.Calc
def filtered_regions():
    """Reactive calculation: updates when inputs change"""
    selected = input.region_filter()
    return regions[regions['SA2_name'].isin(selected)]

5.4 Understanding Reactivity

5.4.1 The Reactive Graph

Shiny automatically tracks dependencies between inputs, calculations, and outputs:

[Input: region_filter] ──→ [@reactive.Calc: filtered_regions] ──→ [Output: map]
                      ──→                                       ──→ [Output: table]

When region_filter changes: 1. filtered_regions() recalculates automatically 2. Both map and table outputs update 3. Other unaffected outputs remain unchanged

1. Inputs - User controls

app_ui = ui.page_fluid(

2. Reactive Calculations - Shared computations

def server(input, output, session):
    
    @reactive.Calc
    def base_data():
        """Load and process base data"""
        gdf = gpd.read_file('data/regions.gpkg')
        return calculate_density(gdf)
    
    @reactive.Calc
    def filtered_data():
        """Filter based on user inputs - depends on base_data"""
        data = base_data()  # Uses reactive
        selected = input.regions()
        return data[data['name'].isin(selected)]
    
    @reactive.Calc
    def summary_stats():
        """Calculate statistics - depends on filtered_data"""
        data = filtered_data()  # Uses another reactive
        return {
            'count': len(data),
            'mean_density': data['density'].mean(),
            'total_pop': data['population'].sum()
        }

3. Outputs - What users see

@output
@render.plot
def density_map():
    """Render matplotlib plot"""
    data = filtered_data()
    fig, ax = plt.subplots()
    data.plot(column='density', ax=ax, legend=True)
    return fig

@output
@render.table
def summary_table():
    """Render pandas DataFrame"""
    return filtered_data()[['name', 'population', 'density']]

@output
@render.text
def stats_text():
    """Render formatted text"""
    stats = summary_stats()
    return f"Selected {stats['count']} regions with mean density {stats['mean_density']:.1f}"

@output
@render.ui
def dynamic_controls():
    """Render dynamic UI elements"""
    data = base_data()
    choices = data['name'].tolist()
    return ui.input_selectize("regions", "Regions", choices=choices, multiple=True)

5.5 Practical Example: Auckland SA2 Dashboard

Let’s build a complete example filtering Auckland SA2 areas:

from shiny import App, ui, render, reactive
import geopandas as gpd
import matplotlib.pyplot as plt
import pandas as pd

# Load data once at startup
auckland_sa2 = gpd.read_file('data/auckland_sa2.gpkg')
auckland_sa2['area_km2'] = auckland_sa2.geometry.area / 1_000_000
auckland_sa2['pop_density'] = auckland_sa2['population'] / auckland_sa2['area_km2']

# Get unique SA2 names for dropdown
sa2_names = sorted(auckland_sa2['SA2_name'].unique().tolist())

# UI Definition
app_ui = ui.page_fluid(
    ui.h2("Auckland SA2 Dashboard"),
    
    ui.layout_sidebar(
        ui.panel_sidebar(
            ui.h4("Filters"),
            
            ui.input_selectize(
                "selected_sa2",
                "Select SA2 Areas",
                choices=sa2_names,
                multiple=True,
                selected=sa2_names[:5]  # Default to first 5
            ),
            
            ui.input_slider(
                "min_population",
                "Minimum Population",
                min=0,
                max=int(auckland_sa2['population'].max()),
                value=0,
                step=1000
            ),
            
            ui.input_checkbox(
                "show_labels",
                "Show Area Names on Map",
                value=False
            ),
            
            ui.hr(),
            ui.h4("Summary Statistics"),
            ui.output_text_verbatim("stats_summary")
        ),
        
        ui.panel_main(
            ui.navset_tab(
                ui.nav("Map", ui.output_plot("choropleth_map")),
                ui.nav("Table", ui.output_table("data_table")),
                ui.nav("Chart", ui.output_plot("density_chart"))
            )
        )
    )
)

# Server Function
def server(input, output, session):
    
    # Reactive calculation: filtered dataset
    @reactive.Calc
    def filtered_data():
        """Filter SA2 areas based on user selections"""
        data = auckland_sa2.copy()
        
        # Filter by selected SA2 names
        selected = input.selected_sa2()
        if selected:  # Only filter if something selected
            data = data[data['SA2_name'].isin(selected)]
        
        # Filter by minimum population
        data = data[data['population'] >= input.min_population()]
        
        return data
    
    # Reactive calculation: summary statistics
    @reactive.Calc
    def summary_statistics():
        """Calculate summary stats for filtered data"""
        data = filtered_data()
        
        if len(data) == 0:
            return {
                'count': 0,
                'total_pop': 0,
                'mean_density': 0,
                'max_density': 0
            }
        
        return {
            'count': len(data),
            'total_pop': int(data['population'].sum()),
            'mean_density': data['pop_density'].mean(),
            'max_density': data['pop_density'].max(),
            'total_area': data['area_km2'].sum()
        }
    
    # Output: Summary statistics text
    @output
    @render.text
    def stats_summary():
        """Display formatted summary statistics"""
        stats = summary_statistics()
        
        if stats['count'] == 0:
            return "No areas match the current filters"
        
        return f"""
Selected Areas: {stats['count']}
Total Population: {stats['total_pop']:,}
Total Area: {stats['total_area']:.1f} km²
Mean Density: {stats['mean_density']:.1f} people/km²
Max Density: {stats['max_density']:.1f} people/km²
        """.strip()
    
    # Output: Choropleth map
    @output
    @render.plot
    def choropleth_map():
        """Create choropleth map of population density"""
        data = filtered_data()
        
        if len(data) == 0:
            # Return empty plot with message
            fig, ax = plt.subplots(figsize=(10, 8))
            ax.text(0.5, 0.5, 'No data to display',
                   ha='center', va='center', fontsize=16)
            ax.set_xlim(0, 1)
            ax.set_ylim(0, 1)
            ax.axis('off')
            return fig
        
        # Create map
        fig, ax = plt.subplots(figsize=(10, 8))
        data.plot(
            column='pop_density',
            ax=ax,
            legend=True,
            cmap='YlOrRd',
            edgecolor='black',
            linewidth=0.5,
            legend_kwds={
                'label': 'Population Density (per km²)',
                'orientation': 'horizontal'
            }
        )
        
        # Add labels if requested
        if input.show_labels():
            for idx, row in data.iterrows():
                centroid = row.geometry.centroid
                ax.annotate(
                    row['SA2_name'],
                    xy=(centroid.x, centroid.y),
                    fontsize=6,
                    ha='center'
                )
        
        ax.set_title('Population Density by SA2', fontsize=14, fontweight='bold')
        ax.set_axis_off()
        plt.tight_layout()
        
        return fig
    
    # Output: Data table
    @output
    @render.table
    def data_table():
        """Display filtered data as table"""
        data = filtered_data()
        
        if len(data) == 0:
            return pd.DataFrame({'Message': ['No data matches filters']})
        
        # Select and format columns
        display_cols = ['SA2_name', 'population', 'area_km2', 'pop_density']
        table_data = data[display_cols].copy()
        
        # Rename for display
        table_data.columns = ['SA2 Name', 'Population', 'Area (km²)', 'Density (per km²)']
        
        # Sort by density
        table_data = table_data.sort_values('Density (per km²)', ascending=False)
        
        # Format numbers
        table_data['Population'] = table_data['Population'].apply(lambda x: f"{int(x):,}")
        table_data['Area (km²)'] = table_data['Area (km²)'].apply(lambda x: f"{x:.2f}")
        table_data['Density (per km²)'] = table_data['Density (per km²)'].apply(lambda x: f"{x:.1f}")
        
        return table_data
    
    # Output: Density chart
    @output
    @render.plot
    def density_chart():
        """Create bar chart of top densities"""
        data = filtered_data()
        
        if len(data) == 0:
            fig, ax = plt.subplots(figsize=(10, 6))
            ax.text(0.5, 0.5, 'No data to display',
                   ha='center', va='center', fontsize=16)
            ax.axis('off')
            return fig
        
        # Get top 10 by density
        top_data = data.nlargest(10, 'pop_density')
        
        # Create horizontal bar chart
        fig, ax = plt.subplots(figsize=(10, 6))
        ax.barh(
            range(len(top_data)),
            top_data['pop_density'],
            color='steelblue',
            alpha=0.7
        )
        ax.set_yticks(range(len(top_data)))
        ax.set_yticklabels(top_data['SA2_name'])
        ax.set_xlabel('Population Density (per km²)')
        ax.set_title('Top 10 Highest Density SA2 Areas', fontweight='bold')
        ax.grid(axis='x', alpha=0.3)
        plt.tight_layout()
        
        return fig

# Create app
app = App(app_ui, server)

5.6 Advanced Reactive Patterns

5.6.1 Pattern 1: Debouncing Rapid Changes

Prevent excessive recalculation when inputs change rapidly:

@reactive.Calc
def filtered_data():
    """Only recalculate after user stops adjusting slider"""
    with reactive.isolate():
        # Wait until user finishes moving slider
        min_val = input.min_value()
    return data[data['value'] >= min_val]

5.6.2 Pattern 2: Conditional Reactivity

Only trigger updates when relevant inputs change:

@reactive.Effect
@reactive.event(input.update_button)  # Only run when button clicked
def update_data():
    """Manual update triggered by button"""

5.6.3 Pattern 3: Reactive Values

Create reactive values that can be programmatically updated:

from shiny import reactive

def server(input, output, session):
    # Create a reactive value
    selected_features = reactive.Value([])
    
    @reactive.Effect
    @reactive.event(input.map_click)
    def handle_click():
        """Update selected features when map is clicked"""
        current = selected_features()
        current.append(input.map_click())
        selected_features.set(current)
    
    @output
    @render.text
    def selection_count():
        return f"Selected {len(selected_features())} features"

Show progress for long-running operations:

from shiny import ui

@reactive.Calc
def validated_radius():
    """Ensure input is within valid range"""
    radius = input.radius()
    if radius < 1:
        return 1
    elif radius > 50:
        return 50
    return radius
