2.2. DataFrames and Pandas

Introduction

In Section 2.1, you learned Python fundamentals: lists for storing sequences, loops for iteration, and conditionals for decision-making. Now we’ll build on those foundations to work with structured tabular data—the kind you’d see in Excel spreadsheets or GIS attribute tables.

This section introduces: - Dictionaries: Flexible key-value structures (essential for GeoJSON and APIs) - pandas DataFrames: Python’s answer to spreadsheets and database tables - Data operations: Reading, filtering, grouping, and transforming data

Why this matters for GIS: Most spatial analysis involves attribute data alongside geometry. You’ll spend significant time manipulating tables before (or after) spatial operations. These skills are foundational for Section 2.4 (GeoPandas), where you’ll add spatial capabilities to DataFrames.

The progression: - Section 2.1: Basics (lists, loops, if/else) - Section 2.2: Structured data (dictionaries, DataFrames, operations) - Section 2.3: Visualisation (making sense of your data) - Section 2.4: Spatial data (adding geography)

Dictionaries: Flexible Data Structures

What is a Dictionary?

Remember lists from Section 2.1? They store items by position:

cities = ['Auckland', 'Wellington', 'Christchurch']
print(cities[0])  # Auckland

Dictionaries store items by key instead of position:

populations = {
    'Auckland': 1672000,
    'Wellington': 217200,
    'Christchurch': 389700
}
print(populations['Auckland'])  # 1672000

Think of a dictionary as a lookup table: you provide a key, it gives you a value.

Creating Dictionaries

# Simple dictionary - city populations
city_pop = {
    "Auckland": 1672000,
    "Wellington": 217200,
    "Christchurch": 389700,
    "Hamilton": 185000,
    "Tauranga": 158000
}

# Access by key
print(city_pop["Auckland"])  # 1672000

# Add new entry
city_pop["Dunedin"] = 134600

# Modify existing
city_pop["Auckland"] = 1700000  # Updated estimate

# Check if key exists
if "Napier" in city_pop:
    print("Found Napier")
else:
    print("Napier not in dictionary")

Dictionary Methods

# Get all keys
city_pop.keys()
# Output: dict_keys(['Auckland', 'Wellington', ...])

# Get all values
city_pop.values()
# Output: dict_values([1672000, 217200, ...])

# Get key-value pairs
city_pop.items()
# Output: dict_items([('Auckland', 1672000), ...])

# Safe access with default
city_pop.get('Napier', 0)  # Returns 0 if key doesn't exist

Iterating Through Dictionaries

Remember for loops from Section 2.1? They work great with dictionaries:

# Iterate through keys
for city in city_pop.keys():
    print(city)

# Iterate through values
for population in city_pop.values():
    print(f"{population:,}")

# Iterate through both (most common!)
for city, population in city_pop.items():
    print(f"{city}: {population:,}")

Output:

Auckland: 1,672,000
Wellington: 217,200
Christchurch: 389,700
...

Connection to Section 2.1: This uses the same for loop syntax you learned, but now with dictionaries instead of lists!

Nested Dictionaries

Dictionaries can contain other dictionaries or lists. This is where they become powerful:

# Auckland transport data
auckland_transport = {
    "buses": {
        "Inner Link": {"daily_riders": 12000, "route_length_km": 6.5},
        "Outer Link": {"daily_riders": 8500, "route_length_km": 8.2},
        "City Link": {"daily_riders": 15000, "route_length_km": 4.2}
    },
    "trains": {
        "Eastern Line": {"daily_riders": 22000, "route_length_km": 28.0},
        "Western Line": {"daily_riders": 18500, "route_length_km": 22.0}
    }
}

# Access nested data
print(auckland_transport["buses"]["Inner Link"]["daily_riders"])  # 12000

# Iterate through nested structure (using Section 2.1 loops!)
for mode, routes in auckland_transport.items():
    print(f"\n{mode.upper()}:")
    for route_name, data in routes.items():
        print(f"  {route_name}: {data['daily_riders']:,} riders")

Why Dictionaries Matter for GIS

Dictionaries are Everywhere in GIS

GeoJSON - the web standard for geographic data - is built entirely on dictionaries:

# A GeoJSON point feature (this is a dictionary!)
auckland_point = {
    "type": "Feature",
    "geometry": {
        "type": "Point",
        "coordinates": [174.7633, -36.8485]  # longitude, latitude
    },
    "properties": {
        "name": "Auckland",
        "population": 1672000,
        "country": "New Zealand"
    }
}

# Access the coordinates
coords = auckland_point["geometry"]["coordinates"]
print(f"Auckland is at {coords[1]}°S, {coords[0]}°E")

# Access properties
print(f"Population: {auckland_point['properties']['population']:,}")

Why this format? - Flexible: Not all features need the same properties - Web-friendly: JavaScript uses identical syntax (hence “JSON”) - Nested: Geometry and attributes kept separate but together

Real-world example: When you fetch data from LINZ Data Service API or OpenStreetMap API, you get dictionaries like this!

Getting Started with Pandas

What is pandas?

pandas is Python’s data analysis library. It provides: - DataFrame: A table with rows and columns (like Excel) - Series: A single column of data - Operations for filtering, grouping, merging data

Think of it as “Excel in Python, but more powerful and reproducible.”

Installation and Import

# Install with uv (if not already installed)
# uv add pandas

# Import with standard alias
import pandas as pd
import numpy as np  # Often used together
Standard Aliases

The Python community uses these aliases consistently: - pandas → pd - numpy → np - matplotlib.pyplot → plt - seaborn → sns - geopandas → gpd (you’ll see this in Section 2.4!)

Using standard aliases makes your code readable to other Python users.

Creating DataFrames

What is a DataFrame?

A DataFrame is a two-dimensional table with: - Rows (observations/records) - Columns (variables/fields) - Index (row labels, usually numbers)

GIS context: Think of it as an attribute table without the geometry column (yet—that comes in Section 2.4 with GeoPandas).

From a Dictionary (The Key Connection!)

This is where dictionaries and DataFrames connect:

# Step 1: Create a dictionary (Section 2.2 beginning!)
city_data = {
    'city': ['Auckland', 'Wellington', 'Christchurch', 'Hamilton', 'Tauranga'],
    'population': [1672000, 217200, 389700, 185000, 158000],
    'area_km2': [1086, 444, 608, 877, 135],
    'region': ['Auckland', 'Wellington', 'Canterbury', 'Waikato', 'Bay of Plenty']
}

# Step 2: Convert to DataFrame
cities_df = pd.DataFrame(city_data)

# Step 3: View it
print(cities_df)

Output:

          city  population  area_km2           region
0     Auckland     1672000      1086         Auckland
1   Wellington      217200       444       Wellington
2  Christchurch      389700       608        Canterbury
3     Hamilton      185000       877          Waikato
4     Tauranga      158000       135  Bay of Plenty

Notice: - Each dictionary key becomes a column name - Each list in the dictionary becomes a column - Pandas automatically adds an index (0, 1, 2, 3, 4)

From a List of Dictionaries

Sometimes data comes as multiple dictionaries (common from APIs):

# Auckland parks (like an API might return)
parks_list = [
    {"name": "Albert Park", "area_ha": 6.0, "suburb": "Auckland CBD"},
    {"name": "Victoria Park", "area_ha": 7.5, "suburb": "Auckland CBD"},
    {"name": "Myers Park", "area_ha": 4.0, "suburb": "Auckland CBD"},
    {"name": "Western Springs", "area_ha": 43.0, "suburb": "Westmere"}
]

# Convert to DataFrame
parks_df = pd.DataFrame(parks_list)
print(parks_df)

Output:

              name  area_ha        suburb
0      Albert Park      6.0  Auckland CBD
1    Victoria Park      7.5  Auckland CBD
2       Myers Park      4.0  Auckland CBD
3  Western Springs     43.0      Westmere

This is exactly what you’ll do with GeoJSON! Each feature becomes a row.

Reading Data Files

CSV Files

CSV (Comma-Separated Values) is the most common format for tabular data.

Basic reading:

# Read local file
df = pd.read_csv('auckland_buses.csv')

# Read from URL
url = 'https://example.com/data.csv'
df = pd.read_csv(url)

Common arguments:

# Specify separator (default is comma)
df = pd.read_csv('data.txt', sep='\t')  # Tab-separated
df = pd.read_csv('data.csv', sep=';')   # Semicolon-separated

# Skip rows at the beginning (e.g., metadata lines)
df = pd.read_csv('data.csv', skiprows=2)  # Skip first 2 rows

# Specify which row is the header
df = pd.read_csv('data.csv', header=0)    # First row (default)
df = pd.read_csv('data.csv', header=None) # No header row

# Specify data types for columns
df = pd.read_csv('data.csv', dtype={'population': int, 'name': str})

# Handle missing values
df = pd.read_csv('data.csv', na_values=['NA', 'missing', '-', ''])

# Use a specific column as index
df = pd.read_csv('data.csv', index_col='city_name')

# Parse dates automatically
df = pd.read_csv('data.csv', parse_dates=['date_column'])

# Read only certain columns
df = pd.read_csv('data.csv', usecols=['city', 'population', 'area'])

# Read only first n rows
df = pd.read_csv('data.csv', nrows=100)

# Specify encoding (for non-UTF-8 files)
df = pd.read_csv('data.csv', encoding='utf-8')
df = pd.read_csv('data.csv', encoding='latin-1')  # Sometimes needed for old files

Practical example:

# Reading Auckland bus route data with specific settings
buses = pd.read_csv(
    'auckland_buses.csv',
    sep=',',                    # Comma-separated
    skiprows=1,                 # Skip metadata line
    header=0,                   # Next row is header
    dtype={
        'route_number': str,    # Keep as string (e.g., "70")
        'daily_riders': int,
        'route_length': float
    },
    na_values=['NA', 'missing'],
    parse_dates=['start_date'],
    usecols=['route_number', 'route_name', 'daily_riders', 'route_length']
)

print(buses.head())
print(buses.dtypes)  # Check data types

Excel Files

# Read Excel file
df = pd.read_excel('data.xlsx')

# Specify sheet by name
df = pd.read_excel('data.xlsx', sheet_name='Sheet1')

# Specify sheet by index (0-based)
df = pd.read_excel('data.xlsx', sheet_name=0)

# Read all sheets into a dictionary
all_sheets = pd.read_excel('data.xlsx', sheet_name=None)
print(all_sheets.keys())  # See all sheet names

# Other arguments work similarly to read_csv
df = pd.read_excel(
    'auckland_demographics.xlsx',
    sheet_name='Suburbs',
    skiprows=2,
    usecols='A:D',  # Columns A through D
    dtype={'population': int}
)

JSON Files

Perfect for working with API responses and GeoJSON!

# Read JSON file
df = pd.read_json('data.json')

# Read from URL (API endpoint)
api_url = 'https://api.example.com/auckland/parks'
df = pd.read_json(api_url)

# For nested JSON (like GeoJSON), you might need to normalize
import json

# Read GeoJSON
with open('auckland_parks.geojson', 'r') as f:
    geojson = json.load(f)

# Extract properties into DataFrame
features = geojson['features']
properties_list = [f['properties'] for f in features]
df = pd.DataFrame(properties_list)

print(df)

Saving DataFrames

# Save to CSV
df.to_csv('output.csv', index=False)  # index=False avoids extra column

# Save to Excel
df.to_excel('output.xlsx', sheet_name='Data', index=False)

# Save to JSON
df.to_json('output.json', orient='records', indent=2)

# Save with specific encoding
df.to_csv('output.csv', encoding='utf-8', index=False)

Selecting Data

Selecting Columns

# Single column (returns Series)
pop_series = suburbs['population']
print(type(pop_series))  # <class 'pandas.core.series.Series'>

# Single column (returns DataFrame)
pop_df = suburbs[['population']]
print(type(pop_df))  # <class 'pandas.core.frame.DataFrame'>

# Multiple columns
subset = suburbs[['suburb', 'population', 'median_income']]
print(subset)

Selecting Rows by Index

Using .iloc[] (integer location):

# Single row by position
first_row = suburbs.iloc[0]  # First row
print(first_row)

# Multiple rows by position
first_three = suburbs.iloc[0:3]  # Rows 0, 1, 2
print(first_three)

# Specific rows
selected = suburbs.iloc[[0, 2, 4]]  # Rows 0, 2, 4
print(selected)

# Rows and columns together
subset = suburbs.iloc[0:3, 0:2]  # First 3 rows, first 2 columns
print(subset)

Using .loc[] (label-based):

# Single row by index label
row = suburbs.loc[0]

# Multiple rows
rows = suburbs.loc[0:2]  # Includes row 2 (unlike iloc!)

# Specific columns
subset = suburbs.loc[:, ['suburb', 'population']]

# Rows and columns
subset = suburbs.loc[0:2, ['suburb', 'population']]

Difference between .iloc and .loc: - .iloc[0:3] → rows 0, 1, 2 (excludes 3) - .loc[0:3] → rows 0, 1, 2, 3 (includes 3 if it exists)

Boolean Indexing (Filtering)

This is the most powerful selection method! It uses conditionals from Section 2.1.

# Find wealthy suburbs (income > 90000)
wealthy = suburbs[suburbs['median_income'] > 90000]
print(wealthy)

# Find affordable housing (price < 1.5M)
affordable = suburbs[suburbs['avg_house_price'] < 1.5]
print(affordable)

# Multiple conditions (AND) - use &
wealthy_and_affordable = suburbs[
    (suburbs['median_income'] > 80000) & 
    (suburbs['avg_house_price'] < 1.5)
]
print(wealthy_and_affordable)

# Multiple conditions (OR) - use |
edge_suburbs = suburbs[
    (suburbs['population'] < 9000) | 
    (suburbs['population'] > 18000)
]
print(edge_suburbs)

# Using .isin() for multiple values
cbd_suburbs = suburbs[suburbs['suburb'].isin(['Mt Eden', 'Parnell', 'Newmarket'])]
print(cbd_suburbs)

# String methods
parks_many = suburbs[suburbs['suburb'].str.contains('Park')]  # Contains "Park"
starts_with_p = suburbs[suburbs['suburb'].str.startswith('P')]  # Starts with P

The .query() Method

Cleaner syntax for filtering:

# Simple condition
wealthy = suburbs.query('median_income > 90000')

# Multiple conditions
ideal = suburbs.query('median_income > 80000 and avg_house_price < 1.8')

# Using variables (with @)
threshold = 90000
high_income = suburbs.query('median_income > @threshold')

# String matching
parnell = suburbs.query('suburb == "Parnell"')

Manipulating Data

Creating New Columns

# Calculate population density (people per km²)
# First, add area_km2 column
suburbs['area_km2'] = [4.2, 2.1, 3.8, 2.9, 6.5, 1.8]

suburbs['density'] = suburbs['population'] / suburbs['area_km2']
print(suburbs[['suburb', 'population', 'area_km2', 'density']])

# Calculate affordability ratio
suburbs['price_to_income'] = (suburbs['avg_house_price'] * 1000000) / suburbs['median_income']

# Conditional column creation (using .apply())
def income_category(income):
    if income < 70000:
        return 'Lower'
    elif income < 90000:
        return 'Middle'
    else:
        return 'Upper'

suburbs['income_category'] = suburbs['median_income'].apply(income_category)
print(suburbs[['suburb', 'median_income', 'income_category']])

# Using np.where for simple conditionals
suburbs['size_category'] = np.where(suburbs['population'] > 12000, 'Large', 'Small')

# Multiple conditions with np.select
conditions = [
    suburbs['population'] < 9000,
    suburbs['population'] < 15000,
    suburbs['population'] >= 15000
]
choices = ['Small', 'Medium', 'Large']
suburbs['size'] = np.select(conditions, choices, default='Unknown')

Modifying Columns

# Update values
suburbs['avg_house_price'] = suburbs['avg_house_price'] * 1.05  # 5% increase

# Round values
suburbs['avg_house_price'] = suburbs['avg_house_price'].round(2)

# Replace values
suburbs['suburb'] = suburbs['suburb'].str.replace('Grey Lynn', 'Gray Lynn')

# Rename columns
suburbs = suburbs.rename(columns={
    'avg_house_price': 'avg_price_millions',
    'parks_count': 'num_parks'
})

Deleting Columns and Rows

# Delete columns
suburbs = suburbs.drop(columns=['size_category'])

# Delete rows by index
suburbs = suburbs.drop([0, 1])  # Delete first two rows

# Delete rows based on condition
suburbs = suburbs[suburbs['population'] > 8500]  # Keep only if population > 8500

# Reset index after deleting rows
suburbs = suburbs.reset_index(drop=True)

Grouping and Aggregation

Grouping is one of pandas’ most powerful features. It follows the split-apply-combine pattern.

Basic Grouping

# Add region column to our data
suburbs['region'] = ['Central', 'Eastern', 'Western', 'Western', 'Central', 'Central']

# Calculate average population by region
avg_pop_by_region = suburbs.groupby('region')['population'].mean()
print(avg_pop_by_region)

Output:

region
Central    14100.0
Eastern     8400.0
Western    10550.0
Name: population, dtype: float64

Multiple Aggregations

# Multiple statistics for one column
region_stats = suburbs.groupby('region')['population'].agg(['mean', 'sum', 'count'])
print(region_stats)

Output:

              mean     sum  count
region                          
Central   14100.0  42300      3
Eastern    8400.0   8400      1
Western   10550.0  21100      2

Aggregating Multiple Columns

# Different aggregations for different columns
summary = suburbs.groupby('region').agg({
    'population': ['mean', 'sum'],
    'median_income': 'mean',
    'avg_price_millions': ['mean', 'max'],
    'num_parks': 'sum'
})

print(summary)

Custom Aggregation Functions

# Define custom function
def price_range(prices):
    return prices.max() - prices.min()

# Use it in groupby
price_ranges = suburbs.groupby('region')['avg_price_millions'].agg([
    'mean',
    ('range', price_range),
    'count'
])
print(price_ranges)

Handling Missing Data

Real-world data is messy. Here’s how to handle it.

Detecting Missing Data

# Create data with missing values
suburbs_missing = pd.DataFrame({
    'suburb': ['Mt Eden', 'Parnell', 'Grey Lynn', 'Ponsonby'],
    'population': [15200, None, 11300, 9800],
    'median_income': [78000, 92000, None, 88000],
    'avg_price': [1.2, 1.8, 1.1, None]
})

# Check for missing values
print(suburbs_missing.isnull())
print(suburbs_missing.isnull().sum())  # Count per column
print(suburbs_missing.isnull().sum().sum())  # Total missing

Output:

   suburb  population  median_income  avg_price
0   False       False          False      False
1   False        True          False      False
2   False       False           True      False
3   False       False          False       True

suburb           0
population       1
median_income    1
avg_price        1
dtype: int64

Total: 3

Removing Missing Data

# Drop rows with ANY missing values
clean = suburbs_missing.dropna()
print(clean)

# Drop rows where specific column is missing
clean = suburbs_missing.dropna(subset=['population'])

# Drop columns with ANY missing values
clean = suburbs_missing.dropna(axis=1)

Filling Missing Data

# Fill with a specific value
filled = suburbs_missing.fillna(0)

# Fill with column mean
suburbs_missing['population'] = suburbs_missing['population'].fillna(
    suburbs_missing['population'].mean()
)

# Fill with column median
suburbs_missing['median_income'] = suburbs_missing['median_income'].fillna(
    suburbs_missing['median_income'].median()
)

# Forward fill (use previous value)
filled = suburbs_missing.fillna(method='ffill')

# Backward fill (use next value)
filled = suburbs_missing.fillna(method='bfill')

# Fill different columns with different values
suburbs_missing = suburbs_missing.fillna({
    'population': suburbs_missing['population'].median(),
    'median_income': suburbs_missing['median_income'].mean(),
    'avg_price': suburbs_missing['avg_price'].median()
})

Interpolation

For time series or ordered data:

# Linear interpolation
suburbs_missing['population'] = suburbs_missing['population'].interpolate(method='linear')

Best Practices

Handling Missing Data Thoughtfully

Before removing or filling: 1. Understand WHY data is missing - Random (safe to fill) - Systematic (e.g., sensor failure - investigate) - By design (e.g., not applicable)

  1. Document your approach
  2. Consider creating a “missing” indicator column
  3. Report how many values you handled

For GIS: Missing coordinates or key identifiers usually mean dropping that record. Missing attributes might be fillable.

Merging DataFrames

Combining datasets is essential for analysis.

Types of Joins

Inner Join

Only keep rows that match in both DataFrames:

# Bus route data
routes = pd.DataFrame({
    'route_id': [1, 2, 3, 4],
    'route_name': ['Inner Link', 'Outer Link', 'City Link', 'Eastern Line']
})

# Ridership data (missing route 4)
ridership = pd.DataFrame({
    'route_id': [1, 2, 3, 5],
    'daily_riders': [12000, 8500, 15000, 6000]
})

# Inner join - only routes with ridership data
merged = pd.merge(routes, ridership, on='route_id', how='inner')
print(merged)

Output:

   route_id   route_name  daily_riders
0         1   Inner Link         12000
1         2   Outer Link          8500
2         3    City Link         15000

Notice: Route 4 (Eastern Line) is missing because no ridership data. Route 5 is missing because it’s not in routes.

Left Join

Keep all rows from left DataFrame:

# Keep all routes, even without ridership data
merged = pd.merge(routes, ridership, on='route_id', how='left')
print(merged)

Output:

   route_id   route_name  daily_riders
0         1   Inner Link       12000.0
1         2   Outer Link        8500.0
2         3    City Link       15000.0
3         4  Eastern Line          NaN

Right Join

Keep all rows from right DataFrame:

# Keep all ridership records, even for unknown routes
merged = pd.merge(routes, ridership, on='route_id', how='right')
print(merged)

Outer Join

Keep all rows from both DataFrames:

# Keep everything
merged = pd.merge(routes, ridership, on='route_id', how='outer')
print(merged)

Merging on Multiple Columns

# Pedestrian counts by location and time
counts = pd.DataFrame({
    'location': ['Queen St', 'Queen St', 'K Rd'],
    'hour': [8, 9, 8],
    'count': [150, 200, 100]
})

# Location metadata
locations = pd.DataFrame({
    'location': ['Queen St', 'K Rd', 'Ponsonby Rd'],
    'district': ['CBD', 'CBD', 'Ponsonby']
})

# Merge on location
merged = pd.merge(counts, locations, on='location', how='left')
print(merged)

Merging with Different Column Names

# Left DataFrame has 'suburb', right has 'location'
df1 = pd.DataFrame({
    'suburb': ['Mt Eden', 'Parnell'],
    'population': [15200, 8400]
})

df2 = pd.DataFrame({
    'location': ['Mt Eden', 'Parnell'],
    'avg_price': [1.2, 1.8]
})

# Merge using left_on and right_on
merged = pd.merge(
    df1, df2,
    left_on='suburb',
    right_on='location',
    how='inner'
)
print(merged)

# Route information
routes = pd.DataFrame({

    'mode': ['Bus', 'Bus', 'Train', 'Train'],
    'route_length_km': [6.5, 8.2, 28.0, 22.0]
})

ridership = pd.DataFrame({
    'route_id': [1, 2, 3, 4],
    'weekday_riders': [12000, 8500, 22000, 18500],
    'weekend_riders': [8000, 6000, 15000, 12000]
})

# Cost data
costs = pd.DataFrame({
    'route_id': [1, 2, 3],  # Missing route 4!
    'annual_cost_millions': [2.5, 3.1, 8.5]
})

# Merge all together
complete = pd.merge(routes, ridership, on='route_id', how='left')
complete = pd.merge(complete, costs, on='route_id', how='left')

# Calculate efficiency metrics
complete['avg_daily_riders'] = (complete['weekday_riders'] * 5 + complete['weekend_riders'] * 2) / 7
complete['riders_per_km'] = complete['avg_daily_riders'] / complete['route_length_km']

# Calculate cost per rider (where available)
complete['cost_per_rider'] = (
    (complete['annual_cost_millions'] * 1e6) / 
    (complete['avg_daily_riders'] * 365)
).round(2)

print(complete)

Complete Workflow Example: Auckland Transit Analysis

Let’s put everything together in a realistic analysis:

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# ============================
# 1. LOAD DATA
# ============================

# Simulate loading from CSV
routes_data = {
    'route_id': [1, 2, 3, 4, 5, 6],
    'route_name': ['Inner Link', 'Outer Link', 'City Link', 
                   'Eastern Line', 'Western Line', 'Northern Express'],
    'mode': ['Bus', 'Bus', 'Bus', 'Train', 'Train', 'Bus'],
    'route_length_km': [6.5, 8.2, 4.2, 28.0, 22.0, 15.0]
}

ridership_data = {
    'route_id': [1, 2, 3, 4, 5, 6],
    'jan_riders': [12000, 8500, 15000, 22000, 18500, 9800],
    'feb_riders': [12200, 8600, 15200, 21800, 18300, 9900],
    'mar_riders': [11800, None, 14900, 22200, 18700, 9700]  # Missing data!
}

routes = pd.DataFrame(routes_data)
ridership = pd.DataFrame(ridership_data)

print("Initial data loaded")
print(f"Routes: {routes.shape}")
print(f"Ridership: {ridership.shape}")

# ============================
# 2. DATA CLEANING
# ============================

# Check for missing values
print("\nMissing values in ridership:")
print(ridership.isnull().sum())

# Fill missing values with mean of that route
ridership['mar_riders'] = ridership['mar_riders'].fillna(
    ridership['mar_riders'].mean()
)

print("Missing values handled")

# ============================
# 3. MERGE DATA
# ============================

# Merge routes and ridership
combined = pd.merge(routes, ridership, on='route_id', how='left')
print(f"\nCombined data: {combined.shape}")

# ============================
# 4. FEATURE ENGINEERING
# ============================

# Calculate average monthly ridership
combined['avg_monthly_riders'] = combined[['jan_riders', 'feb_riders', 'mar_riders']].mean(axis=1)

# Calculate efficiency (riders per km)
combined['efficiency'] = combined['avg_monthly_riders'] / combined['route_length_km']

# Categorize by ridership level
def ridership_category(riders):
    if riders < 10000:
        return 'Low'
    elif riders < 15000:
        return 'Medium'
    else:
        return 'High'

combined['ridership_category'] = combined['avg_monthly_riders'].apply(ridership_category)

# Add cost estimates ($/km/month)
cost_per_km = {'Bus': 5000, 'Train': 8000}
combined['monthly_cost'] = combined.apply(
    lambda row: row['route_length_km'] * cost_per_km[row['mode']], 
    axis=1
)

# ============================
# 5. ANALYSIS
# ============================

print("\n" + "="*50)
print("ANALYSIS RESULTS")
print("="*50)

# Summary by transport mode
mode_summary = combined.groupby('mode').agg({
    'avg_monthly_riders': ['sum', 'mean'],
    'route_length_km': 'mean',
    'efficiency': 'mean',
    'monthly_cost': 'sum'
}).round(2)

print("\nSummary by Transport Mode:")
print(mode_summary)

# Top routes by ridership
top_routes = combined.nlargest(3, 'avg_monthly_riders')[
    ['route_name', 'mode', 'avg_monthly_riders', 'efficiency']
]
print("\nTop 3 Routes by Ridership:")
print(top_routes)

# Most efficient routes
efficient = combined.nlargest(3, 'efficiency')[
    ['route_name', 'efficiency', 'avg_monthly_riders']
]
print("\nMost Efficient Routes (riders/km):")
print(efficient)

# Cost analysis
cost_summary = combined.groupby('mode')['monthly_cost'].agg(['sum', 'mean']).round(0)
print("\nMonthly Cost by Mode:")
print(cost_summary)

# ============================
# 6. VisualisATION
# ============================

fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Plot 1: Ridership by route
combined.plot(
    kind='bar',
    x='route_name',
    y='avg_monthly_riders',
    ax=axes[0, 0],
    color='steelblue',
    legend=False
)
axes[0, 0].set_title('Average Monthly Ridership by Route', fontweight='bold')
axes[0, 0].set_xlabel('')
axes[0, 0].set_ylabel('Monthly Riders')
axes[0, 0].tick_params(axis='x', rotation=45)

# Plot 2: Efficiency comparison
combined.plot(
    kind='barh',
    x='route_name',
    y='efficiency',
    ax=axes[0, 1],
    color='forestgreen',
    legend=False
)
axes[0, 1].set_title('Route Efficiency (Riders/km)', fontweight='bold')
axes[0, 1].set_xlabel('Riders per km')
axes[0, 1].set_ylabel('')

# Plot 3: Mode comparison
mode_totals = combined.groupby('mode')['avg_monthly_riders'].sum()
axes[1, 0].pie(mode_totals, labels=mode_totals.index, autopct='%1.1f%%')
axes[1, 0].set_title('Total Ridership Share by Mode', fontweight='bold')

# Plot 4: Monthly trends for top 3 routes
top_3_routes = combined.nlargest(3, 'avg_monthly_riders')
months = ['Jan', 'Feb', 'Mar']
for _, route in top_3_routes.iterrows():
    riders = [route['jan_riders'], route['feb_riders'], route['mar_riders']]
    axes[1, 1].plot(months, riders, marker='o', label=route['route_name'])
axes[1, 1].set_title('Monthly Trends - Top 3 Routes', fontweight='bold')
axes[1, 1].set_ylabel('Riders')
axes[1, 1].legend()
axes[1, 1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

combined.to_csv('auckland_transport_analysis.csv', index=False)
