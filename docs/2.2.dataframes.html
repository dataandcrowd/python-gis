2.2. DataFrames

Introduction

Working with tabular data is fundamental to geospatial analysis. Most spatial datasets combine attribute data (stored in tables) with geographic information. This section introduces pandas, Python’s powerful library for data manipulation, which forms the foundation for working with geopandas (spatial data) later in this course.

What is a DataFrame?

A DataFrame is a two-dimensional tabular data structure with labelled rows and columns—essentially a spreadsheet in Python. It’s the most common way to work with structured data.

DataFrames can be thought of as: - A table with rows and columns - A collection of Series (columns) that share an index - A dictionary where each key is a column name

Dictionaries: Building Blocks

Before diving into DataFrames, let’s understand dictionaries—Python’s key-value data structure that underpins much of pandas.

Dictionary Basics

A dictionary stores data as key:value pairs:

# Create a dictionary
city_populations = {
    "Auckland": 1672000,
    "Wellington": 217200,
    "Christchurch": 389700
}

# Access values by key
print(city_populations["Auckland"])  # Output: 1672000

# Add a new entry
city_populations["Hamilton"] = 185000

# Modify an existing value
city_populations["Auckland"] = 1700000

Dictionary Methods

# Get all keys
city_populations.keys()
# Output: dict_keys(['Auckland', 'Wellington', 'Christchurch', 'Hamilton'])

# Get all values
city_populations.values()
# Output: dict_values([1700000, 217200, 389700, 185000])

# Get key-value pairs
city_populations.items()
# Output: dict_items([('Auckland', 1700000), ('Wellington', 217200), ...])

Iterating Through Dictionaries

# Iterate through keys
for city in city_populations.keys():
    print(city)

# Iterate through key-value pairs
for city, population in city_populations.items():
    print(f"{city}: {population:,}")

# Output:
# Auckland: 1,700,000
# Wellington: 217,200
# Christchurch: 389,700
# Hamilton: 185,000

Nested Dictionaries

Dictionaries can contain other dictionaries or lists—useful for complex data:

staff = {
    "people": [
        {"name": "Hyesop", "role": "lecturer"},
        {"name": "Sila", "role": "lecturer"},
        {"name": "Oliver", "role": "tutor"}
    ],
    "pets": [
        {"name": "Pepper", "species": "dog"},
        {"name": "Pip", "species": "dog"},
        {"name": "Harriet", "species": "cat"}
    ]
}

# Access nested data
print(staff["people"][0]["name"])  # Output: Hyesop
Why Dictionaries Matter for GIS

Geospatial data formats like GeoJSON are built on nested dictionaries:

{
  "type": "Feature",
  "geometry": {"type": "Point", "coordinates": [174.76, -36.85]},
  "properties": {"name": "Auckland", "population": 1672000}
}

Selecting Data

Selecting Columns

# Single column (returns Series)
ages = df['Age']

# Multiple columns (returns DataFrame)
subset = df[['Name', 'City']]

# Using dot notation (only for valid Python identifiers)
ages = df.Age

Selecting Rows

# By position using iloc
first_row = df.iloc[0]           # First row
first_three = df.iloc[0:3]       # First 3 rows
specific_rows = df.iloc[[0, 2, 4]]  # Rows 0, 2, 4

# By label using loc
row_by_label = df.loc[0]         # Row with index 0

Boolean Indexing (Filtering)

Filter rows based on conditions:

# Simple filter
high_age = df[df['Age'] > 20]

# Multiple conditions with &, |
filtered = df[(df['Age'] > 18) & (df['City'] == 'Auckland')]

# Using isin for multiple values
cities_subset = df[df['City'].isin(['Auckland', 'Wellington'])]

# String methods
starts_with_a = df[df['Name'].str.startswith('A')]
contains_ck = df[df['City'].str.contains('ck')]
Boolean Operators
  • & for AND (not and)
  • | for OR (not or)
  • ~ for NOT (not not)
  • Always use parentheses around each condition!

The Query Method

A more readable alternative to boolean indexing:

# Simple query
filtered = df.query('Age > 20')

# Multiple conditions
filtered = df.query('Age > 18 and City == "Auckland"')

# Using variables with @
min_age = 18
filtered = df.query('Age > @min_age')

Practical Example: Filtering Pedestrian Data

# Load data
pedestrians = pd.read_csv('pedestrian_counts.csv')

# Filter for weekdays only
weekdays = pedestrians[pedestrians['day_of_week'] < 5]

# Filter for high foot traffic
high_traffic = pedestrians[pedestrians['count'] > 1000]

morning_rush = pedestrians[
    (pedestrians['day_of_week'] < 5) &
    (pedestrians['hour'] >= 7) &
    (pedestrians['hour'] <= 9) &
    (pedestrians['count'] > 500)
]

# Find specific location
queen_street = pedestrians.query('location == "Queen Street"')

# Filter by date range
recent = pedestrians[pedestrians['date'] >= '2023-01-01']

Adding and Modifying Columns

Creating New Columns

# From calculation
df['Age_in_months'] = df['Age'] * 12

# From existing columns
df['Full_info'] = df['Name'] + ' from ' + df['City']

# Conditional values
df['Category'] = 'Adult'  # Set all to 'Adult'
df.loc[df['Age'] < 18, 'Category'] = 'Minor'  # Override for minors

# Using apply with a function
def age_group(age):
    if age < 18:
        return 'Youth'
    elif age < 65:
        return 'Adult'
    else:
        return 'Senior'

df['Age_Group'] = df['Age'].apply(age_group)

Practical Example: Processing Pedestrian Data

# Calculate hourly average from minute counts
pedestrians['hourly_average'] = pedestrians['total_count'] / 60

# Create time period categories
def classify_time(hour):
    if 6 <= hour < 9:
        return 'Morning Rush'
    elif 9 <= hour < 12:
        return 'Morning'
    elif 12 <= hour < 14:
        return 'Lunch'
    elif 14 <= hour < 17:
        return 'Afternoon'
    elif 17 <= hour < 20:
        return 'Evening Rush'
    else:
        return 'Night'

pedestrians['time_period'] = pedestrians['hour'].apply(classify_time)

# Flag weekends
pedestrians['is_weekend'] = pedestrians['day_of_week'] >= 5

# Calculate change from previous measurement
pedestrians['count_change'] = pedestrians['count'].diff()

Grouping and Aggregation

Grouping is one of pandas’ most powerful features—it follows a split-apply-combine strategy:

  1. Split data into groups based on criteria
  2. Apply a function to each group
  3. Combine results into a data structure

Basic Grouping

# Group by single column and calculate mean
city_stats = df.groupby('City')['Age'].mean()

# Multiple aggregations
city_summary = df.groupby('City').agg({
    'Age': ['mean', 'min', 'max'],
    'Name': 'count'
})

# Group by multiple columns
df.groupby(['City', 'Category'])['Age'].mean()

Common Aggregation Functions

Function Description
count() Count non-null values
sum() Sum of values
mean() Average value
median() Median value
min() Minimum value
max() Maximum value
std() Standard deviation
var() Variance

Practical Example: Analysing Pedestrian Patterns

# Average count by location
location_avg = pedestrians.groupby('location')['count'].mean()
print(location_avg.sort_values(ascending=False).head())

# Statistics by time of day
time_stats = pedestrians.groupby('time_period').agg({
    'count': ['mean', 'std', 'max'],
    'location': 'count'
})

# Weekend vs weekday comparison
day_type_comparison = pedestrians.groupby('is_weekend')['count'].agg([
    'mean', 'median', 'max'
]).round(0)

# Hourly patterns by location
hourly_patterns = pedestrians.groupby(['location', 'hour'])['count'].mean()

# Find peak hour for each location
peak_hours = pedestrians.groupby('location').apply(
    lambda x: x.loc[x['count'].idxmax(), 'hour']
)

# Multi-level grouping: location and time period
detailed_stats = pedestrians.groupby(['location', 'time_period']).agg({
    'count': ['mean', 'max'],
    'date': 'count'  # Number of observations
}).round(0)

Reshaping Data: Melt and Pivot

Melt: Wide to Long Format

Convert wide data (multiple value columns) to long format:

# Wide format
df_wide = pd.DataFrame({
    'City': ['Auckland', 'Wellington', 'Christchurch'],
    'Jan_Temp': [25, 22, 20],
    'Feb_Temp': [24, 21, 19],
    'Mar_Temp': [23, 20, 18]
})

# Convert to long format
df_long = pd.melt(
    df_wide,
    id_vars=['City'],           # Columns to keep
    var_name='Month',            # Name for variable column
    value_name='Temperature'     # Name for value column
)

print(df_long)

Output:

          City      Month  Temperature
0     Auckland   Jan_Temp           25
1   Wellington   Jan_Temp           22
2  Christchurch   Jan_Temp           20
3     Auckland   Feb_Temp           24
4   Wellington   Feb_Temp           21
...

Pivot: Long to Wide Format

# Convert back to wide format
df_pivot = df_long.pivot(
    index='City',
    columns='Month',
    values='Temperature'
)
When to Melt

Melting is useful when: - You have multiple columns representing the same type of data - You want to use groupby or plot with seaborn - Your data needs to be in “tidy” format for analysis

Handling Missing Data

Real-world data often has missing values. Pandas provides tools to handle them:

Detecting Missing Data

# Check for any missing values
df.isnull().any()        # Any missing per column?
df.isnull().sum()        # Count missing per column
df.isnull().sum().sum()  # Total missing values

# Check specific column
df['Age'].isnull()       # Boolean mask
df['Age'].isnull().sum() # Count

Removing Missing Data

# Drop rows with any missing values
df_clean = df.dropna()

# Drop rows with missing values in specific columns
df_clean = df.dropna(subset=['Age', 'City'])

# Drop columns with any missing values
df_clean = df.dropna(axis=1)

# Drop rows where all values are missing
df_clean = df.dropna(how='all')

Filling Missing Data

# Fill with a specific value
df['Age'].fillna(0)

# Fill with mean
df['Age'].fillna(df['Age'].mean())

# Fill with median
df['Age'].fillna(df['Age'].median())

# Forward fill (use previous value)
df['Age'].fillna(method='ffill')

# Backward fill (use next value)
df['Age'].fillna(method='bfill')

# Fill with interpolation
df['Age'].interpolate()

Practical Example: Cleaning Pedestrian Data

# Check for missing values
print("Missing values per column:")
print(pedestrians.isnull().sum())

# Count-specific cleaning
# Option 1: Remove rows with missing counts
pedestrians_clean = pedestrians.dropna(subset=['count'])

# Option 2: Fill with median (more robust than mean for outliers)
median_count = pedestrians['count'].median()
pedestrians['count'].fillna(median_count, inplace=True)

# Option 3: Forward fill for time series data
pedestrians_sorted = pedestrians.sort_values(['location', 'datetime'])
pedestrians_sorted['count'].fillna(method='ffill', inplace=True)

# Fill location names
pedestrians['location'].fillna('Unknown', inplace=True)

# Verify cleaning
print("\nAfter cleaning:")
print(pedestrians.isnull().sum())

Merging and Joining DataFrames

Combining data from multiple sources is common in geospatial analysis.

Types of Joins

  • Inner: Only matching rows from both DataFrames
  • Left: All rows from left DataFrame, matching from right
  • Right: All rows from right DataFrame, matching from left
  • Outer: All rows from both DataFrames

Merge Example

# Create two DataFrames
df1 = pd.DataFrame({
    'ID': [1, 2, 3, 4],
    'Name': ['Tom', 'Nick', 'Krish', 'Jack'],
    'Age': [20, 21, 19, 18]
})

df2 = pd.DataFrame({
    'ID': [3, 4, 5, 6],
    'Subject': ['Maths', 'English', 'Science', 'History'],
    'Score': [88, 75, 90, 85]
})

# Inner join (only matching IDs: 3, 4)
inner = pd.merge(df1, df2, on='ID', how='inner')

# Left join (all from df1)
left = pd.merge(df1, df2, on='ID', how='left')

# Outer join (all from both)
outer = pd.merge(df1, df2, on='ID', how='outer')

Practical Example: Combining Pedestrian and Location Data

# Pedestrian counts
counts = pd.DataFrame({
    'location_id': [1, 1, 2, 2, 3, 3],
    'hour': [8, 9, 8, 9, 8, 9],
    'count': [150, 200, 300, 350, 100, 120]
})

# Location details
locations = pd.DataFrame({
    'location_id': [1, 2, 3, 4],
    'location_name': ['Queen St', 'Karangahape Rd', 'Ponsonby Rd', 'Broadway'],
    'district': ['CBD', 'CBD', 'Ponsonby', 'Newmarket']
})

# Merge to add location names
merged = pd.merge(counts, locations, on='location_id', how='left')
print(merged)

Practical Workflow Example

Here’s a complete workflow analysing Auckland pedestrian data:

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# 1. Read and explore data
pedestrians = pd.read_csv('auckland_pedestrian_counts.csv')
print("Dataset shape:", pedestrians.shape)
print("\nFirst few rows:")
print(pedestrians.head())

# 2. Data cleaning
# Check for missing values
print("\nMissing values:")
print(pedestrians.isnull().sum())

# Fill missing counts with median
pedestrians['count'].fillna(pedestrians['count'].median(), inplace=True)

# Remove any remaining rows with critical missing data
pedestrians.dropna(subset=['location', 'datetime'], inplace=True)

# 3. Feature engineering
# Convert datetime
pedestrians['datetime'] = pd.to_datetime(pedestrians['datetime'])
pedestrians['hour'] = pedestrians['datetime'].dt.hour
pedestrians['day_of_week'] = pedestrians['datetime'].dt.dayofweek
pedestrians['is_weekend'] = pedestrians['day_of_week'] >= 5

# Create time period categories
def classify_time(hour):
    if 6 <= hour < 9:
        return 'Morning Rush'
    elif 9 <= hour < 12:
        return 'Morning'
    elif 12 <= hour < 14:
        return 'Lunch'
    elif 14 <= hour < 17:
        return 'Afternoon'
    elif 17 <= hour < 20:
        return 'Evening Rush'
    else:
        return 'Night'

pedestrians['time_period'] = pedestrians['hour'].apply(classify_time)

# 4. Analysis
# Find busiest locations
busiest_locations = pedestrians.groupby('location')['count'].agg([
    'mean', 'median', 'max', 'count'
]).sort_values('mean', ascending=False)
print("\nBusiest locations:")
print(busiest_locations.head())

# Compare weekday vs weekend
day_type_stats = pedestrians.groupby('is_weekend')['count'].agg([
    'mean', 'median', 'std'
]).round(0)
print("\nWeekday vs Weekend:")
print(day_type_stats)

# Peak hours by location
peak_hours = pedestrians.groupby('location').apply(
    lambda x: x.loc[x['count'].idxmax(), ['hour', 'count']]
)
print("\nPeak hours by location:")
print(peak_hours)

# 5. Visualisation
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# Hourly pattern
hourly_avg = pedestrians.groupby('hour')['count'].mean()
axes[0, 0].plot(hourly_avg.index, hourly_avg.values, marker='o')
axes[0, 0].set_title('Average Count by Hour')
axes[0, 0].set_xlabel('Hour of Day')
axes[0, 0].set_ylabel('Average Count')
axes[0, 0].grid(True, alpha=0.3)

# Top locations
top_10 = busiest_locations.head(10)['mean']
axes[0, 1].barh(range(len(top_10)), top_10.values)
axes[0, 1].set_yticks(range(len(top_10)))
axes[0, 1].set_yticklabels(top_10.index)
axes[0, 1].set_title('Top 10 Busiest Locations')
axes[0, 1].set_xlabel('Average Count')

# Weekday vs weekend distribution
pedestrians.boxplot(column='count', by='is_weekend', ax=axes[1, 0])
axes[1, 0].set_title('Weekday vs Weekend Distribution')
axes[1, 0].set_xlabel('Is Weekend')
axes[1, 0].set_ylabel('Count')

# Time period comparison
period_avg = pedestrians.groupby('time_period')['count'].mean().sort_values()
axes[1, 1].barh(range(len(period_avg)), period_avg.values, color='steelblue')
axes[1, 1].set_yticks(range(len(period_avg)))
axes[1, 1].set_yticklabels(period_avg.index)
axes[1, 1].set_title('Average Count by Time Period')
axes[1, 1].set_xlabel('Average Count')

plt.tight_layout()
plt.show()

# 6. Export results
# Save cleaned data
pedestrians.to_csv('pedestrians_cleaned.csv', index=False)

# Save summary statistics
busiest_locations.to_csv('location_summary.csv')

print("\nAnalysis complete!")

Summary
