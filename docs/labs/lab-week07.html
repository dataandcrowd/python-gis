Overview

You now know your assigned Assignment 2 track (announced on 21 April at 13:10). This lab is the main build session: by the end of it, your Shiny app should load real data, draw a map, draw a chart, and respond to at least one meaningful user input.

We will not start from a blank file. The Shinylive examples gallery is a collection of small, runnable Shiny apps that cover every pattern you need. You will pick a handful, copy the bits that match your track, and stitch them into your own app. This mirrors how working developers build dashboards: find a working example, adapt, then refine.

Duration: approximately 2 hours (during the ANZAC break, so pace yourself over the week).

  • Your track assignment confirmed (Track A, B, or C).

Section 2: How to use the Shinylive examples gallery

shinylive.io/py/examples is the single most useful bookmark for this assignment. Every example is:

  • A complete, runnable Shiny app in your browser.
  • Paired with the full source code, which you can copy or edit in-place.
  • Packaged so shinylive will load it without you installing anything.

How to read an example

For each example you open, ask three questions:

  1. What input does it take? (slider, dropdown, file upload, nothing)
  2. What output does it produce? (text, plot, map, table)
  3. How does the server function connect them? (a @render.*, a @reactive.calc, a @reactive.event)

Once you can answer those three, copying the example into your own app is just substitution: your data replaces theirs, your colours replace theirs, your filter replaces theirs.

A small adaptation workflow

  1. Open the example on shinylive.
  2. Click Edit on Shinylive (top-right).
  3. Change one thing. Watch the app rebuild automatically in the preview pane.
  4. Change one more thing. Repeat.
  5. When you understand the pattern, copy the code into your local app.py and swap in your data.

This “change one thing at a time” habit is the fastest way to learn Shiny. Do not copy the whole file into your project and then try to make it work; you will end up debugging five things at once.

Section 3: Shared building blocks (all tracks)

Three patterns every track needs. Each one has a matching gallery example you should skim before the track exercise.

Block 1: Inputs that share one reactive calc

Gallery example to open: the basic Reactive inputs app at shinylive.io/py/examples. Look at how a slider and a dropdown feed a single @reactive.calc, and how two outputs read that calc.

Skeleton you will use in every track:

from shiny import App, ui, render, reactive
import pandas as pd

data = pd.read_csv("data/your_track_data.csv")

app_ui = ui.page_sidebar(
    ui.sidebar(
        ui.input_select("category", "Category",
                        choices=["All"] + sorted(data["category"].unique().tolist())),
        ui.input_slider("min_value", "Minimum value", 0, 100, 0),
        ui.input_checkbox("only_recent", "Only recent", value=False),
    ),
    ui.output_text("summary"),
    ui.output_plot("chart"),
    title="My track dashboard",
)

def server(input, output, session):

    @reactive.calc
    def filtered():
        df = data.copy()
        if input.category() != "All":
            df = df[df["category"] == input.category()]
        df = df[df["value"] >= input.min_value()]
        if input.only_recent():
            df = df[df["year"] >= 2020]
        return df

    @render.text
    def summary():
        return f"{len(filtered())} rows after filters."

    @render.plot
    def chart():
        df = filtered()
        return df.plot.bar(x="category", y="value")  # placeholder

app = App(app_ui, server)

Three inputs, one @reactive.calc, two outputs that both read it. That is the minimum you need for Part B of the rubric.

Block 2: An ipyleaflet map inside Shiny

Gallery example to open: search the gallery for ipyleaflet or map. The example uses output_widget in the UI and @render_widget in the server, via shinywidgets.

Skeleton:

from shiny import App, ui, reactive
from shinywidgets import output_widget, render_widget
from ipyleaflet import Map, Marker, GeoData
import geopandas as gpd

layer = gpd.read_file("data/your_geodata.geojson").to_crs(4326)

app_ui = ui.page_sidebar(
    ui.sidebar(
        ui.input_slider("min_value", "Minimum value", 0, 100, 0),
    ),
    output_widget("map"),
    title="My track map",
)

def server(input, output, session):

    @reactive.calc
    def filtered_layer():
        return layer[layer["value"] >= input.min_value()]

    @render_widget
    def map():
        m = Map(center=(-36.85, 174.77), zoom=11)
        m.add_layer(GeoData(
            geo_dataframe=filtered_layer(),
            style={"color": "#d73027", "weight": 2, "fillOpacity": 0.4},
        ))
        return m

app = App(app_ui, server)

Two things to remember:

  • CRS: ipyleaflet needs WGS84 (EPSG:4326). Call .to_crs(4326) when you load.
  • Layer refresh: return a new Map each time inside @render_widget. Trying to mutate a stored Map object often fails to trigger a re-render.

Block 3: A Plotly or matplotlib chart

Gallery examples to open: Plotly, or Matplotlib. Pick whichever syntax you are happier with. Plotly gives you interactive hover; matplotlib is simpler.

Matplotlib version (works everywhere):

import matplotlib.pyplot as plt

@render.plot
def chart():
    df = filtered()
    fig, ax = plt.subplots(figsize=(7, 4))
    ax.bar(df["category"], df["value"], color="steelblue")
    ax.set_xlabel("Category")
    ax.set_ylabel("Value")
    plt.tight_layout()
    return fig

Plotly version (interactive hover, zoom):

from shinywidgets import output_widget, render_widget
import plotly.express as px

# In the UI:
# output_widget("chart")

@render_widget
def chart():
    return px.bar(filtered(), x="category", y="value")

Either counts as the quantitative chart for Part C.

Goal: a dashboard that shows AT’s monthly patronage time series paired with a map of bus or ferry routes. The user can filter by mode.

Data preparation (do once, outside the Shiny app):

# scripts/prep_patronage.py
import pandas as pd

# Downloaded CSV from https://at.govt.nz/about-us/at-data-sources
raw = pd.read_csv("data_raw/at_patronage.csv")

# Tidy: one row per (month, mode)
tidy = (raw
    .melt(id_vars="Month", var_name="mode", value_name="boardings")
    .dropna()
)
tidy["Month"] = pd.to_datetime(tidy["Month"])
tidy.to_csv("data/patronage.csv", index=False)

For the routes layer, download Bus service, layer 2 from AT GIS, save as data/bus_routes.geojson, and simplify:

Starter app:

from shiny import App, ui, render, reactive
from shinywidgets import output_widget, render_widget
from ipyleaflet import Map, GeoData
import pandas as pd, geopandas as gpd
import matplotlib.pyplot as plt

patronage = pd.read_csv("data/patronage.csv", parse_dates=["Month"])
routes    = gpd.read_file("data/bus_routes.geojson").to_crs(4326)

modes = sorted(patronage["mode"].unique().tolist())

app_ui = ui.page_sidebar(
    ui.sidebar(
        ui.input_checkbox_group("modes", "Modes", choices=modes, selected=modes),
        ui.input_slider("year_from", "From year", 2014, 2025, 2018),
        ui.input_radio_buttons("map_type", "Map layer",
                               choices=["Bus routes", "(none)"], selected="Bus routes"),
    ),
    ui.card(ui.card_header("Patronage over time"), ui.output_plot("chart")),
    ui.card(ui.card_header("Network map"), output_widget("map")),
    title="AT patronage explorer",
)

def server(input, output, session):

    @reactive.calc
    def filtered_patronage():
        df = patronage[patronage["mode"].isin(input.modes())]
        df = df[df["Month"].dt.year >= input.year_from()]
        return df

    @render.plot
    def chart():
        df = filtered_patronage()
        fig, ax = plt.subplots(figsize=(8, 4))
        for mode, sub in df.groupby("mode"):
            ax.plot(sub["Month"], sub["boardings"], label=mode)
        ax.set_ylabel("Boardings")
        ax.legend()
        plt.tight_layout()
        return fig

    @render_widget
    def map():
        m = Map(center=(-36.85, 174.77), zoom=11)
        if input.map_type() == "Bus routes":
            m.add_layer(GeoData(
                geo_dataframe=routes,
                style={"color": "#d73027", "weight": 2, "opacity": 0.7},
            ))
        return m

app = App(app_ui, server)

Goal: a dashboard that lets the user pick an SA2 and see, side-by-side, where workers vs students travel to.

Data preparation (do once):

# scripts/prep_od.py
import pandas as pd, geopandas as gpd

commuters = pd.read_csv("data_raw/commuters_2023.csv")
students  = pd.read_csv("data_raw/students_2023.csv")
sa2       = gpd.read_file("data_raw/sa2_2023.geojson").to_crs(2193)

# Clip to Auckland region only (keeps file size small)
auckland = sa2[sa2["region_name"] == "Auckland"]
auckland.geometry = auckland.geometry.simplify(tolerance=20)
auckland = auckland[["SA2_code", "SA2_name", "geometry"]]
auckland.to_file("data/sa2_auckland.geojson", driver="GeoJSON")

# Long format for both populations
def tidy(df, label):
    df = df.rename(columns={"origin_SA2": "origin",
                            "destination_SA2": "dest",
                            "count": "n"})
    df["population"] = label
    return df[["origin", "dest", "n", "population"]]

pd.concat([tidy(commuters, "worker"), tidy(students, "student")]).to_csv(
    "data/od.csv", index=False)

Starter app:

from shiny import App, ui, render, reactive
from shinywidgets import output_widget, render_widget
from ipyleaflet import Map, GeoData
import pandas as pd, geopandas as gpd
import matplotlib.pyplot as plt

od  = pd.read_csv("data/od.csv")
sa2 = gpd.read_file("data/sa2_auckland.geojson").to_crs(4326)

origins = sorted(od["origin"].unique().tolist())

app_ui = ui.page_sidebar(
    ui.sidebar(
        ui.input_select("origin", "Origin SA2", choices=origins, selected=origins[0]),
        ui.input_checkbox_group("pops", "Populations",
                                choices=["worker", "student"],
                                selected=["worker", "student"]),
        ui.input_slider("top_n", "Top N destinations", 5, 30, 10),
    ),
    ui.card(ui.card_header("Top destinations"), ui.output_plot("chart")),
    ui.card(ui.card_header("Destinations on the map"), output_widget("map")),
    title="Commuter vs Student OD (Auckland)",
)

def server(input, output, session):

    @reactive.calc
    def subset():
        df = od[(od["origin"] == input.origin()) &
                (od["population"].isin(input.pops()))]
        top = (df.groupby(["dest", "population"])["n"].sum()
                 .reset_index()
                 .sort_values("n", ascending=False)
                 .head(input.top_n()))
        return top

    @render.plot
    def chart():
        df = subset()
        fig, ax = plt.subplots(figsize=(8, 4))
        for pop, sub in df.groupby("population"):
            ax.barh(sub["dest"], sub["n"], label=pop, alpha=0.6)
        ax.invert_yaxis()
        ax.legend()
        plt.tight_layout()
        return fig

    @render_widget
    def map():
        df = subset()
        dests = sa2[sa2["SA2_code"].isin(df["dest"].unique())]
        m = Map(center=(-36.85, 174.77), zoom=10)
        m.add_layer(GeoData(
            geo_dataframe=dests,
            style={"color": "#1f78b4", "fillColor": "#a6cee3",
                   "opacity": 0.7, "fillOpacity": 0.5, "weight": 1},
        ))
        return m

app = App(app_ui, server)

Goal: a dashboard that shows crash points on the map with filters for year, severity, and mode involved, paired with a chart of counts.

Data preparation (do once):

# scripts/prep_crashes.py
import pandas as pd, geopandas as gpd

# Download crash dataset from the AT link in 3.6
raw = pd.read_csv("data_raw/crashes_auckland.csv")

# Keep the columns you will actually use
keep = ["crash_year", "severity", "mode", "latitude", "longitude", "day_of_week"]
raw = raw[keep].dropna(subset=["latitude", "longitude"])

gdf = gpd.GeoDataFrame(
    raw,
    geometry=gpd.points_from_xy(raw["longitude"], raw["latitude"]),
    crs="EPSG:4326",
)

# Trim for shinylive: last 5 years only
gdf = gdf[gdf["crash_year"] >= 2019]
gdf.to_file("data/crashes.geojson", driver="GeoJSON")

Starter app:

from shiny import App, ui, render, reactive
from shinywidgets import output_widget, render_widget
from ipyleaflet import Map, CircleMarker, LayerGroup
import geopandas as gpd
import matplotlib.pyplot as plt

crashes = gpd.read_file("data/crashes.geojson").to_crs(4326)

severities = sorted(crashes["severity"].unique().tolist())
modes      = sorted(crashes["mode"].unique().tolist())

app_ui = ui.page_sidebar(
    ui.sidebar(
        ui.input_slider("year_range", "Year range",
                        2019, 2024, (2019, 2024), sep=""),
        ui.input_checkbox_group("severity", "Severity",
                                choices=severities, selected=severities),
        ui.input_checkbox_group("mode", "Modes involved",
                                choices=modes, selected=modes),
    ),
    ui.card(ui.card_header("Crashes on the map"), output_widget("map")),
    ui.card(ui.card_header("Crash counts"), ui.output_plot("chart")),
    title="Auckland crashes",
)

def server(input, output, session):

    @reactive.calc
    def filtered():
        lo, hi = input.year_range()
        df = crashes[
            crashes["crash_year"].between(lo, hi)
            & crashes["severity"].isin(input.severity())
            & crashes["mode"].isin(input.mode())
        ]
        return df

    @render.plot
    def chart():
        df = filtered()
        counts = df.groupby(["crash_year", "severity"]).size().unstack(fill_value=0)
        fig, ax = plt.subplots(figsize=(8, 4))
        counts.plot(kind="bar", stacked=True, ax=ax)
        ax.set_ylabel("Crashes")
        plt.tight_layout()
        return fig

    @render_widget
    def map():
        df = filtered().head(2000)  # cap rendering cost
        colour_of = {"Fatal": "#b10026", "Serious": "#e31a1c",
                     "Minor": "#fd8d3c", "Non-injury": "#fdbb84"}
        markers = [
            CircleMarker(
                location=(row.geometry.y, row.geometry.x),
                radius=3,
                color=colour_of.get(row["severity"], "#636363"),
                fill_color=colour_of.get(row["severity"], "#636363"),
                fill_opacity=0.7,
            )
            for _, row in df.iterrows()
        ]
        m = Map(center=(-36.85, 174.77), zoom=11)
        m.add_layer(LayerGroup(layers=tuple(markers)))
        return m

app = App(app_ui, server)

  2. Add a shinyswatch theme of your choosing: ui.page_sidebar(..., theme=shinyswatch.theme.flatly()).

  4. Begin a report.qmd in your repo: add the YAML header from 3.6 and the five section headings, even if each section is only a placeholder for now.

Common problems

  • The map does not show after deploy. Check that you called .to_crs(4326) on your GeoDataFrame. ipyleaflet will silently show an empty map for data in NZTM.
  • @render_widget never updates. Make sure you are creating a new Map() inside the function, not reusing a Map defined at module level.
  • The app works locally but shinylive shows “Package not found”. Pyodide does not ship every package. For this assignment you should only need: shiny, shinywidgets, ipyleaflet, pandas, geopandas, matplotlib, optionally plotly and shinyswatch. If you pulled in something else, remove it.
  • The deploy is huge and slow to load. Check your data/ folder. Simplify polygons, drop unused columns, and trim to the Auckland region only.
