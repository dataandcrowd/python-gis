Why Momepy?

Urban form influences how people move. More connected, human-scale streets tend to have higher pedestrian activity, better walkability scores, and more vibrant urban life. Momepy lets us quantify these characteristics so that we can move beyond subjective judgements and test hypotheses with data.

Part 1: Street Networks with OSMnx

About OSMnx

OSMnx is a Python library that downloads street network data from OpenStreetMap and converts it into a NetworkX graph. We can then extract nodes (intersections and dead ends) and edges (street segments) as GeoDataFrames for spatial analysis.

Task 1: Downloading the Auckland CBD Network

import osmnx as ox
import geopandas as gpd
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# Download the walkable street network for Auckland CBD
# network_type='walk' includes footpaths, pedestrian streets, and shared paths
# We use a bounding box centred on the CBD to capture the sensor area
G = ox.graph_from_bbox(
    bbox=(-36.839, -36.862, 174.755, 174.775),
    network_type='walk'
)

print(f"Nodes (intersections): {G.number_of_nodes()}")
print(f"Edges (street segments): {G.number_of_edges()}")
# Convert the graph to GeoDataFrames
nodes, edges = ox.graph_to_gdfs(G)

print(f"Nodes shape: {nodes.shape}")
print(f"Edges shape: {edges.shape}")
# Inspect the nodes table
nodes.head()
# Inspect the edges table
edges.head()

Part 2: Morphological Measures with Momepy

Momepy provides functions to quantify the morphological characteristics of urban form. We focus on three street network measures that are relevant to walkability: node degree, meshedness, and closeness centrality.

Task 3: Node Degree

Node degree is the number of street segments meeting at an intersection. A 4-way intersection has degree 4; a dead end has degree 1. Higher average degree indicates a more connected, grid-like network with more route choices for pedestrians.

import momepy

# Calculate node degree
# momepy expects the graph as a NetworkX object
degree_dict = dict(G.degree())

# Add degree to the nodes GeoDataFrame
nodes["degree"] = nodes.index.map(degree_dict)

print(f"Average node degree: {nodes['degree'].mean():.2f}")
print(f"Maximum degree: {nodes['degree'].max()}")
print(f"Minimum degree: {nodes['degree'].min()}")
# Distribution of node degrees
print(nodes["degree"].value_counts().sort_index())
# Map node degree
fig, ax = plt.subplots(figsize=(10, 10))

nodes.plot(
    ax=ax,
    column="degree",
    cmap="YlOrRd",
    markersize=nodes["degree"] * 8,
    edgecolor="black",
    linewidth=0.3,
    legend=True,
    legend_kwds={"label": "Node Degree", "shrink": 0.6}
)

edges.plot(ax=ax, color="#cccccc", linewidth=0.3, zorder=0)

ax.set_title("Auckland CBD: Node Degree (Street Connectivity)", fontweight="bold")
ax.set_axis_off()
plt.tight_layout()
plt.show()
What Does Node Degree Tell Us?

A node with degree 1 is a dead end. Degree 2 means the street simply continues (no intersection). Degree 3 is a T-junction, and degree 4 is a standard crossroads. Nodes with degree 5 or higher are complex intersections with many route choices. For walkability, higher average degree generally means a more permeable network.

Task 4: Closeness Centrality

Closeness centrality measures how close a node is to all other nodes in the network. A node with high closeness centrality can be reached from anywhere in the network with relatively short travel distances. This is a proxy for accessibility.

import networkx as nx

# Calculate closeness centrality using network distance (edge length)
centrality = nx.closeness_centrality(G, distance="length")

# Add to nodes GeoDataFrame
nodes["closeness"] = nodes.index.map(centrality)

print(f"Mean closeness centrality: {nodes['closeness'].mean():.6f}")
print(f"Max closeness centrality: {nodes['closeness'].max():.6f}")
print(f"Min closeness centrality: {nodes['closeness'].min():.6f}")
# Map closeness centrality
fig, ax = plt.subplots(figsize=(10, 10))

nodes.plot(
    ax=ax,
    column="closeness",
    cmap="plasma",
    markersize=15,
    edgecolor="none",
    legend=True,
    legend_kwds={"label": "Closeness Centrality", "shrink": 0.6}
)

edges.plot(ax=ax, color="#cccccc", linewidth=0.3, zorder=0)

ax.set_title("Auckland CBD: Closeness Centrality", fontweight="bold")
ax.set_axis_off()
plt.tight_layout()
plt.show()

Task 5: Betweenness Centrality

Betweenness centrality measures how often a node lies on the shortest path between other pairs of nodes. A node with high betweenness is a critical route through the network. Removing it would force pedestrians to take longer detours.

# Calculate betweenness centrality (may take a moment)
betweenness = nx.betweenness_centrality(G, weight="length")

nodes["betweenness"] = nodes.index.map(betweenness)

print(f"Mean betweenness: {nodes['betweenness'].mean():.6f}")
print(f"Max betweenness: {nodes['betweenness'].max():.6f}")
# Map betweenness centrality
fig, ax = plt.subplots(figsize=(10, 10))

nodes.plot(
    ax=ax,
    column="betweenness",
    cmap="inferno",
    markersize=15,
    edgecolor="none",
    legend=True,
    legend_kwds={"label": "Betweenness Centrality", "shrink": 0.6}
)

edges.plot(ax=ax, color="#cccccc", linewidth=0.3, zorder=0)

ax.set_title("Auckland CBD: Betweenness Centrality", fontweight="bold")
ax.set_axis_off()
plt.tight_layout()
plt.show()
Closeness vs Betweenness

Closeness centrality answers “how easy is it to reach everywhere from here?” whilst betweenness centrality answers “how many shortest paths pass through here?” A node can be highly central by closeness but low by betweenness if it is well-located but not on many through-routes. Both are useful for understanding pedestrian flow patterns.

Task 6: Network Summary Statistics

Momepy and NetworkX together provide several summary statistics that characterise the overall walkability of a street network.

# Basic network statistics from OSMnx
stats = ox.stats.basic_stats(G)

print("=== Network Summary ===")
print(f"Number of nodes:        {stats['n']}")
print(f"Number of edges:        {stats['m']}")
print(f"Average node degree:    {stats['k_avg']:.2f}")
print(f"Total edge length:      {stats['edge_length_total']:.0f} m")
print(f"Average edge length:    {stats['edge_length_avg']:.1f} m")
# Intersection count (nodes with degree > 1)
intersections = nodes[nodes["degree"] > 1]
dead_ends = nodes[nodes["degree"] == 1]

print(f"\nIntersections:          {len(intersections)}")
print(f"Dead ends:              {len(dead_ends)}")
print(f"Dead-end ratio:         {len(dead_ends) / len(nodes):.1%}")
# Meshedness ratio: proportion of actual loops relative to maximum possible
# A higher meshedness means more route choices
n_nodes = G.number_of_nodes()
n_edges = G.number_of_edges()
meshedness = (n_edges - n_nodes + 1) / (2 * n_nodes - 5) if n_nodes > 2 else 0

print(f"\nMeshedness ratio:       {meshedness:.3f}")
print("(0 = tree/no loops, 1 = maximally connected)")
Interpreting Meshedness

A meshedness ratio close to 0 means the network is tree-like with few alternative routes. A ratio closer to 1 means there are many loops and route choices. Most urban street networks fall between 0.1 and 0.5. Higher values generally indicate better walkability because pedestrians have more route options.

Your turn: Compare the meshedness of the walk network with the drive network. Which is more “meshed” and why?

Part 3: Linking Urban Form to Pedestrian Footfall

Now we connect the morphological measures from Part 2 with the pedestrian count data from the Auckland CBD sensors. The central hypothesis is: more connected, more central streets should have higher pedestrian activity.

Task 7: Loading and Preparing the Pedestrian Data

# Load pedestrian counts and geodata
ped = pd.read_csv("data/akl_ped-2024.csv")
geo = pd.read_csv("data/akl_ped-Geodata.csv")

# Clean the pedestrian data
ped = ped.dropna(subset=["Date", "Time"]).copy()
ped = ped[ped["Date"] != "Daylight Savings"].copy()
ped["Date"] = pd.to_datetime(ped["Date"])

# Extract temporal features
ped["hour"] = ped["Time"].str.split(":").str[0].astype(int)
ped["month"] = ped["Date"].dt.month

# Sensor columns
sensor_cols = ped.columns[2:23]

print(f"Pedestrian data: {ped.shape}")
print(f"Sensor locations: {len(geo)}")
# Calculate the annual average hourly count for each sensor
avg_counts = ped[sensor_cols].mean()

# Create a summary table with coordinates
sensor_summary = geo.copy()
sensor_summary["avg_count"] = sensor_summary["Address"].map(avg_counts)
sensor_summary = sensor_summary.dropna(subset=["avg_count"])

print("Average hourly count by sensor:")

Task 8: Creating a Spatial Join

To link pedestrian sensors with network nodes, we need to find the nearest node to each sensor location. This requires projecting both datasets to a metric coordinate reference system (NZGD2000 / New Zealand Transverse Mercator, EPSG:2193).

# Convert sensors to GeoDataFrame
sensor_gdf = gpd.GeoDataFrame(
    sensor_summary,
    geometry=gpd.points_from_xy(sensor_summary["Longitude"], sensor_summary["Latitude"]),
    crs="EPSG:4326"
)

# Project both to NZTM (metres)
sensor_proj = sensor_gdf.to_crs("EPSG:2193")
nodes_proj = nodes.to_crs("EPSG:2193")

print(f"Sensors: {len(sensor_proj)}")
print(f"Network nodes: {len(nodes_proj)}")
# Find the nearest network node for each sensor
from shapely.ops import nearest_points

def find_nearest_node(sensor_point, nodes_gdf):
    """Return the index of the nearest node to a given point."""
    distances = nodes_gdf.geometry.distance(sensor_point)
    nearest_idx = distances.idxmin()
    return nearest_idx, distances[nearest_idx]

# Apply to each sensor
results = sensor_proj.geometry.apply(lambda pt: find_nearest_node(pt, nodes_proj))
sensor_proj["nearest_node"] = results.apply(lambda x: x[0])
sensor_proj["distance_to_node"] = results.apply(lambda x: x[1])

print("Distance from each sensor to its nearest node (metres):")
print(sensor_proj[["Address", "distance_to_node"]].to_string(index=False))
# Join morphological measures from nodes to sensors
sensor_morphology = sensor_proj.merge(
    nodes[["degree", "closeness", "betweenness"]],
    left_on="nearest_node",
    right_index=True,
    how="left"
)

sensor_morphology[["Address", "avg_count", "degree", "closeness", "betweenness"]].round(6)
Spatial Join Caveats

We have only 19 sensor locations, which is a small sample for correlation analysis. The nearest node may not perfectly represent the morphological context of the sensor (a sensor on a long block might be far from the nearest intersection). Interpret results as exploratory rather than confirmatory.

Task 9: Testing the Hypothesis

from scipy.stats import pearsonr, spearmanr

# Pearson correlation: degree vs average footfall
corr_degree, p_degree = pearsonr(
    sensor_morphology["degree"],
    sensor_morphology["avg_count"]
)

# Spearman correlation (rank-based, less sensitive to outliers)
rho_degree, p_rho_degree = spearmanr(
    sensor_morphology["degree"],
    sensor_morphology["avg_count"]
)

print("=== Degree vs Pedestrian Count ===")
print(f"Pearson r  = {corr_degree:.3f}  (p = {p_degree:.3f})")
print(f"Spearman ρ = {rho_degree:.3f}  (p = {p_rho_degree:.3f})")
# Closeness centrality vs footfall
corr_close, p_close = pearsonr(
    sensor_morphology["closeness"],
    sensor_morphology["avg_count"]
)

rho_close, p_rho_close = spearmanr(
    sensor_morphology["closeness"],
    sensor_morphology["avg_count"]
)

print("=== Closeness Centrality vs Pedestrian Count ===")
print(f"Pearson r  = {corr_close:.3f}  (p = {p_close:.3f})")
print(f"Spearman ρ = {rho_close:.3f}  (p = {p_rho_close:.3f})")
# Betweenness centrality vs footfall
corr_btwn, p_btwn = pearsonr(
    sensor_morphology["betweenness"],
    sensor_morphology["avg_count"]
)

rho_btwn, p_rho_btwn = spearmanr(
    sensor_morphology["betweenness"],
    sensor_morphology["avg_count"]
)

print("=== Betweenness Centrality vs Pedestrian Count ===")
print(f"Pearson r  = {corr_btwn:.3f}  (p = {p_btwn:.3f})")
print(f"Spearman ρ = {rho_btwn:.3f}  (p = {p_rho_btwn:.3f})")
Interpreting the Results

A positive correlation means that sensors near more connected/central nodes tend to have higher pedestrian counts. A p-value below 0.05 is conventionally considered statistically significant, but with only 19 observations, treat significance cautiously. The Spearman rank correlation is more robust when the relationship is not strictly linear or when outliers are present.

Task 13: Temporal Variation in Form-Function Relationship

Does the relationship between urban form and pedestrian activity change throughout the day? During the morning rush, commuters may follow direct routes (favouring high-betweenness nodes), whilst at lunchtime, pedestrians may disperse to a wider variety of destinations.

# Calculate average counts by hour for each sensor
target_hours = [7, 9, 12, 15, 17, 20]

hourly_correlations = []

for h in target_hours:
    hour_data = ped[ped["hour"] == h][sensor_cols].mean()

    # Match to sensors with morphology data
    temp = sensor_morphology.copy()
    temp["hour_count"] = temp["Address"].map(hour_data)
    temp = temp.dropna(subset=["hour_count"])

    r_degree, _ = pearsonr(temp["degree"], temp["hour_count"])
    r_close, _ = pearsonr(temp["closeness"], temp["hour_count"])

    hourly_correlations.append({
        "hour": h,
        "r_degree": r_degree,
        "r_closeness": r_close,

Comparing Walkability Measures

Measure What It Captures Walkability Relevance
Node degree Number of streets at an intersection More route choices for pedestrians
Closeness centrality How close to all other nodes Ease of reaching destinations
Betweenness centrality How many shortest paths pass through Importance as a through-route
Meshedness Proportion of loops in network Overall network permeability
Edge length Length of street segments Shorter blocks = more walkable
Which Measure Is Best?

There is no single “best” measure. Node degree is the simplest to interpret but ignores network structure beyond the immediate intersection. Closeness centrality captures global accessibility but is sensitive to the extent of the network analysed. Betweenness centrality identifies critical through-routes but may not reflect where people want to be, only where they must pass through. Use multiple measures together for a richer picture.
